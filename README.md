# AI-Based Radar System using Machine Learning

An AI-powered radar signal processing and classification system developed using Python and supervised machine learning. This project simulates radar signal generation, extracts meaningful features, processes signals, and classifies radar targets using a trained machine learning model.

---

## Project Overview

The objective of this project is to demonstrate how Artificial Intelligence and Digital Signal Processing (DSP) can be integrated to improve radar signal analysis and target classification. The system preprocesses radar signals, extracts features, and uses a trained machine learning model to classify radar data efficiently.

---

## Key Features

- Radar signal simulation
- Digital Signal Processing (DSP)
- Feature extraction from radar signals
- Supervised Machine Learning based classification
- Radar target prediction
- Visualization of processed radar signals
- Modular Python implementation

## Project Structure

```
AI-Based-Radar-System
│
├── app.py                     # Application entry point
├── main.py                    # Main execution file
├── radar_simulator.py         # Simulates radar signal generation
├── signal_processor.py        # Processes radar signals using DSP
├── feature_extractor.py       # Extracts features from radar data
├── classifier.py              # Machine Learning classification module
├── radar_classifier.pkl       # Trained ML model
├── radar_dsp_output.png       # Output visualization
└── test_radar_dsp.py          # Testing script
```

---

## Workflow

1. Generate radar signals using the radar simulator.
2. Process signals using Digital Signal Processing techniques.
3. Extract meaningful numerical features.
4. Load the trained Machine Learning model.
5. Predict radar target classification.
6. Display processed radar signal visualization.

---

## Machine Learning

**Learning Type:** Supervised Machine Learning

The classification model is trained on extracted radar signal features to recognize different radar target patterns and generate accurate predictions.

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/AI-Based-Radar-System.git
```

Move into the project directory:

```bash
cd AI-Based-Radar-System
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
